⚡ TCP Client-Server

A lightweight client-server application written in C++ using Boost.Asio / Asio for asynchronous TCP networking.

✨ Features
🔌 TCP communication between client and server
⚡ Asynchronous I/O with Asio
🧩 Separate client and server components
🚀 Foundation for scalable network applications
🛠️ Tech Stack
C++
Boost.Asio / Asio
TCP/IP
CMake (if used for building)
📁 Project Structure
.
├── client/       # TCP client
├── server/       # TCP server
├── CMakeLists.txt
└── README.md
🚀 Getting Started

Clone the repository:

git clone <repository-url>
cd <project-directory>

Build the project using CMake:

cmake -S . -B build
cmake --build build

Run the server first, then launch the client.

Built to explore modern C++ networking and asynchronous communication.
